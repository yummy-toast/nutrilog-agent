# 第一天：为什么先验证一个工具？

## 输入到输出

1. 用户描述食物，模型决定是否调用工具。
2. Spring AI把工具的名称、说明、参数结构交给模型。
3. 模型返回工具名称和JSON参数，应用执行Java方法。
4. 工具结果返回模型，模型组织答案。

模型不直接访问数据库，也不决定用户身份。Java负责参数检查和业务执行。

本次最小例子：每100克116千卡，重量200克，计算232千卡。116是显式测试数据，并不是已查证的米饭数据。

## 代码阅读顺序

- NutritionTools：输入校验 → BigDecimal运算 → 展示舍入。
- ToolProtocolTest：验证JSON参数能映射到Java工具并返回结果。
- LiveSmokeRunner：真实模型是否确实调用工具；仅显式启用时执行。
